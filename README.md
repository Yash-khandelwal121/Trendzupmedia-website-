# Trendzup Media - IT Development Company Website

A modern, responsive, and high-converting IT Development company website built with React, Tailwind CSS, and Framer Motion.

## Features

- **Mega Menu**: Professional 4-column mega dropdown with smooth animations.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop.
- **Animations**: Subtle and premium scroll/hover animations using Framer Motion.
- **Pages**:
  - Home: Hero, Services Highlight, Why Choose Us, Testimonials, CTA.
  - Services: Comprehensive listing of all offerings.
  - Portfolio: Filterable project grid.
  - Blog: Articles with search and categories.
  - About Us: Mission, Vision, and Team.
  - Contact Us: Integrated form, Google Map, and floating buttons.
- **Tech Stack**:
  - React 18
  - Tailwind CSS
  - Lucide React (Icons)
  - Framer Motion (Animations)
  - React Router DOM (Navigation)

## Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```

## Folder Structure

```text
src/
├── components/
│   ├── layout/       # Navbar, Footer
│   ├── ui/           # Reusable UI components
│   ├── home/         # Home page specific sections
│   └── shared/       # Floating buttons, etc.
├── pages/            # Page components
├── data/             # siteData.js for easy content updates
├── App.jsx           # Routing and Layout
└── index.css         # Global styles and Tailwind
```

## Deployment

This project is ready to be deployed on platforms like **Vercel**, **Netlify**, or **GitHub Pages**. Simply connect your repository and it will automatically build and deploy.
